## Case Study Details

### 91. Registration Record Analyzer
Validates registration records, checks ID format, detects duplicate IDs, and classifies errors.

### 92. Sports Scheduling and Scoring
Stores event schedules, detects time conflicts, calculates team points, and produces rankings.

### 93. Public Transport Fare Reconciliation
Calculates expected passenger fares and compares them with collected revenue to identify discrepancies.

### 94. Disaster Relief Supply Allocation
Allocates limited supplies to areas according to priority and calculates unmet demand.

### 95. Manufacturing Production Planner
Checks raw-material availability, calculates good production, compares production with demand, and detects quality violations.

### 96. Library Resource Distribution
Distributes available books to branches according to priority and identifies unmet demand.

### 97. Campus Incident Prioritization
Calculates incident priority scores using severity and frequency, then ranks maintenance cases.

### 98. Academic Progression Audit
Checks marks, attendance, and prerequisites to decide whether a student is eligible to progress.

### 99. E-Commerce Order Processing
Calculates order value and discounts, updates stock after dispatch and returns, and reports revenue.

### 100. Smart Campus Management Simulation
A menu-driven program that demonstrates student records, attendance, marks, events, resources, and program exit.
